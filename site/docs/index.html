Connect your search accounts.

Node.js 22 or later is required. The npm listing is pending; use the release tarball today.

  1. Download the v0.1.0 release and save the .tgz locally.
  2. Run npx -y --package C:/path/pabsamuel-seo-data-mcp-0.1.0.tgz seo-data-mcp --help.
  3. Prepare Google credentials as below. Add only the keys for the tools you need.
  4. Add the local command to your MCP client and restart it.
  5. Ask it to list Search Console sitemaps for your property.

Claude Desktop

Add this entry under mcpServers in the Desktop configuration. Replace the package and credential paths.

{"seo-data":{"command":"npx","args":["-y","--package","C:/path/pabsamuel-seo-data-mcp-0.1.0.tgz","seo-data-mcp"],"env":{"GOOGLE_APPLICATION_CREDENTIALS":"C:/private/google.json"}}}

Claude Code

claude mcp add --transport stdio --env GOOGLE_APPLICATION_CREDENTIALS=C:/private/google.json seo-data -- npx -y --package C:/path/pabsamuel-seo-data-mcp-0.1.0.tgz seo-data-mcp

After npm publication, replace the local package command with npx -y @pabsamuel/seo-data-mcp@0.1.0. Client-specific installation has not been tested in a signed-in Claude Desktop or Claude Code session; the real MCP stdio protocol test passes.

Google service account

Enable Search Console API in your own Google Cloud project. Create a service account and download its JSON key to a private directory. In Search Console, select your property, then Settings → Users and permissions → Add user; add the service-account email as Full user. Set GOOGLE_APPLICATION_CREDENTIALS to that JSON file. Never upload it here.

Google user OAuth fallback

If service-account access cannot be added, create your own Desktop OAuth client. Configure the consent screen and add yourself as a test user. With Google Cloud CLI installed, run:

gcloud auth application-default login --client-id-file=C:/private/desktop-client.json --scopes=https://www.googleapis.com/auth/webmasters.readonly

Point GOOGLE_APPLICATION_CREDENTIALS to the resulting application_default_credentials.json (authorized_user type). Credentials remain on your device. Testing-mode refresh tokens may expire; reauthorize your own client when required. No shared Atesen OAuth app is used.

Other credentials

BING_API_KEY
Use a Bing Webmaster API key for a site verified in your own account.
GOOGLE_API_KEY
Enable PageSpeed Insights and Chrome UX Report APIs in your project. CrUX requires this key; low-traffic origins can return 404.
INDEXNOW_KEY
Host your key file on the submitted domain. Requests require confirm:true. Submissions may notify search engines; only submit URLs you control.
SEO_MCP_LICENSE_FILE
A private text file containing the paid license. Validation is entirely offline. Do not paste keys into reports or support issues.

Limits and troubleshooting

Local usage is stored at ~/.seo-data-mcp/usage.json. Override the directory with SEO_MCP_STATE_DIR if needed; keep it private. Quota resets at midnight UTC. A stale usage.lock may be removed only after all MCP processes have stopped. There are no automatic retries after provider limits. Inspect your provider console for its reset time.

Search Console returns top rows, not a guaranteed exhaustive export. Paginate with startRow and rowLimit. URL inspection reads Google's indexed version, not a live crawl.
